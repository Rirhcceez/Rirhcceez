## 👨‍💻 About me

I'm a third-year **Computer Engineering and Digital Technology (CEDT)** student at **Chulalongkorn University** who combines **business analysis, data analysis and hands-on software development**. I analyzed national card-payment data at the **Bank of Thailand**, gathered client requirements and built Tableau dashboards at **The Red Carbon**, and I run an **online motorcycle parts store** backed by an order-management system I built myself.
